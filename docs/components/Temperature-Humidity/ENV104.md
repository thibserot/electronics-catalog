# GY-SHT45 High-Precision Temperature & Humidity Sensor - ENV104

High-accuracy I2C temperature and humidity sensor based on Sensirion SHT45 chip. Industry-leading precision with ±0.1°C temperature and ±1% RH accuracy. Perfect for applications requiring precise environmental control.

## Key Specifications

| Parameter | Value |
|-----------|-------|
| **Temperature range** | -40°C to +125°C |
| **Temperature accuracy** | ±0.1°C (typ), ±0.2°C (max) |
| **Humidity range** | 0% to 100% RH (non-condensing) |
| **Humidity accuracy** | ±1.0% RH (10-90% range) |
| **Resolution** | 0.01°C, 0.01% RH (16-bit) |
| **Supply voltage** | 2.15V - 5.5V (3.3V or 5V) |
| **Interface** | I2C (up to 1 MHz) |
| **I2C address** | 0x44 (default, fixed) |
| **Response time** | <8 seconds (humidity 63%) |
| **Current** | ~0.4μA (sleep), ~800μA (measuring) |
| **Quantity** | 2 pieces |

## Pinout (GY-SHT45 Breakout Module)

```
GY-SHT45 Module
   ___
  |   |
  | S |
  |___|
   | | | |
   V G S S
   C N D C
   C D A L

VCC = Power (2.15-5.5V, use 3.3V or 5V)
GND = Ground
SDA = I2C Data (ESP32 GPIO21 default)
SCL = I2C Clock (ESP32 GPIO22 default)
```

## Typical Wiring (ESP32)

```
ESP32           GY-SHT45
-----           --------
3.3V   -------> VCC
GND    -------> GND
GPIO21 -------> SDA
GPIO22 -------> SCL
```

**Pull-ups:** Module has built-in pull-up resistors.

## Example Code (ESP32)

```cpp
// ESP32 + GY-SHT45 (I2C)
// Install: Adafruit SHT4x library + Adafruit Unified Sensor
#include <Wire.h>
#include <Adafruit_SHT4x.h>

Adafruit_SHT4x sht4 = Adafruit_SHT4x();

void setup() {
  Serial.begin(115200);
  Wire.begin();

  if (!sht4.begin()) {
    Serial.println("SHT45 not found! Check wiring.");
    while (1) delay(10);
  }

  Serial.println("SHT45 sensor found");

  // Set precision mode
  // Options: SHT4X_HIGH_PRECISION, SHT4X_MED_PRECISION, SHT4X_LOW_PRECISION
  sht4.setPrecision(SHT4X_HIGH_PRECISION);

  // Set heater (for condensation issues, usually not needed)
  // Options: SHT4X_NO_HEATER, SHT4X_HIGH_HEATER_1S, etc.
  sht4.setHeater(SHT4X_NO_HEATER);
}

void loop() {
  sensors_event_t humidity, temp;

  // Read sensor
  sht4.getEvent(&humidity, &temp);

  // Display with high precision
  Serial.printf("Temp: %.2f°C | Humidity: %.2f%%\n",
                temp.temperature, humidity.relative_humidity);

  delay(2000);
}
```

## Key Features

**High precision:**

- ±0.1°C temperature accuracy (best in class)
- ±1% RH humidity accuracy
- 16-bit resolution (0.01°C steps)

**Wide range:**

- -40°C to +125°C temperature
- 0-100% RH humidity (full range)
- Works in extreme environments

**Low power:**

- Sleep mode: <0.4μA
- Measurement: ~800μA for 8ms
- Perfect for battery applications

**Built-in heater:**

- Can activate internal heater to evaporate condensation
- Useful in high-humidity environments
- Helps prevent sensor drift

## Precision Modes

| Mode | Temp Accuracy | Humidity Accuracy | Measurement Time |
|------|---------------|-------------------|------------------|
| **High** | ±0.1°C | ±1.0% RH | ~8.3ms |
| **Medium** | ±0.2°C | ±1.5% RH | ~4.5ms |
| **Low** | ±0.3°C | ±2.0% RH | ~1.7ms |

Trade-off between precision and speed/power.

## Gotchas

1. **Fixed I2C address:** 0x44 only (cannot be changed)
2. **Condensation:** If used in very humid environment, may need heater mode
3. **First reading:** May be inaccurate after power-on (take 2-3 readings)
4. **Price:** More expensive than DHT11/DHT22 (~$5-8)
5. **Chemical exposure:** Avoid volatile organic compounds (VOCs) near sensor

## Heater Mode Usage

When to use built-in heater:

**Problem:** Condensation on sensor in very humid environments

**Solution:** Activate heater for 1 second to evaporate moisture

```cpp
// Enable heater for 1 second at high power
sht4.setHeater(SHT4X_HIGH_HEATER_1S);
sht4.getEvent(&humidity, &temp);  // Takes measurement with heater
sht4.setHeater(SHT4X_NO_HEATER);  // Turn off heater
```

**Caution:** Heater increases temperature locally - reading will be higher than ambient!

## Calibration

SHT45 comes factory-calibrated and stored in sensor EEPROM. No user calibration needed for typical use.

For ultra-precise work:
- Compare against NIST-traceable reference
- Apply offset correction in software if needed

## Troubleshooting

**Sensor not found:**
- Check I2C wiring (SDA/SCL correct?)
- Verify address is 0x44: `Wire.beginTransmission(0x44)`
- Try I2C scanner sketch

**Humidity reads 100% constantly:**
- Sensor has condensation
- Use heater mode to clear
- Improve ventilation

**Readings drift over time:**
- Normal slight drift (~0.25% RH/year)
- Recalibrate annually for precision work
