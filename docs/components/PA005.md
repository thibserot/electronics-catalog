# Resistor Assortment Box (30 values) — PA005

A loose through-hole resistor box covering 30 common E-series values from **10 Ω to 1 MΩ**.
Wattage/tolerance not marked on the box — assume **1/4 W carbon/metal film** unless measured.
For a precision set with documented ratings, see the metal-film kit **PA006**.

## Values in this box (30)

| Range | Values |
|-------|--------|
| **Ω**  | 10, 22, 47, 100, 150, 200, 220, 270, 330, 470, 510, 680 |
| **kΩ** | 1k, 2k, 2.2k, 3.3k, 4.7k, 5.1k, 6.8k, 10k, 20k, 47k, 51k, 68k, 100k, 220k, 300k, 470k, 680k |
| **MΩ** | 1M |

## Notes
- Quantity per value is not tracked — treat as "a handful of each".
- Colour-code reminder: bands = digit, digit, multiplier, (tolerance). A 4-band gold-tolerance part is ±5%.
- Overlaps heavily with **PA006** (metal-film kit); reach for PA006 when you need a known 1% tolerance.
