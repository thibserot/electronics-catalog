# Soil Moisture Sensor (Capacitive/Resistive) - ENV401

Analog sensor for measuring soil moisture content. Available in capacitive (better) or resistive (cheaper) versions. Perfect for automated plant watering and garden irrigation systems.

## Key Specifications

| Parameter | Value |
|-----------|-------|
| **Supply voltage** | 3.3V - 5V |
| **Output type** | Analog (0-3V) + Digital (threshold) |
| **Sensing method** | Capacitive or resistive |
| **Probe length** | ~20cm typical |
| **Response time** | <1 second |
| **Operating temp** | 0°C to 60°C |
| **Quantity** | 6 pieces (5 new + 1 old) |

## Pinout (Typical Module)

```
Sensor Module
    ___
   |   |
   |___|
   | | | |
   V A D G
   C O O N
   C   U D
       T

VCC  = Power (3.3-5V)
AO   = Analog Output (voltage proportional to moisture)
DO   = Digital Output (threshold trigger)
GND  = Ground
```

**Additional:** Some modules have potentiometer to adjust digital threshold.

## Typical Wiring (ESP32)

```
ESP32           Soil Moisture Sensor
-----           --------------------
3.3V   -------> VCC
GND    -------> GND
GPIO34 -------> AO (Analog Out)
GPIO25 -------> DO (Digital Out, optional)
```

**Note:** Use separate power control pin to avoid sensor degradation.

## Example Code with Power Switching

```cpp
// ESP32 + Soil Moisture Sensor (with power switching)
#define MOISTURE_PIN 34      // Analog input
#define POWER_PIN 25         // Power control (optional but recommended)

void setup() {
  Serial.begin(115200);
  pinMode(POWER_PIN, OUTPUT);
  digitalWrite(POWER_PIN, LOW);  // Start with sensor OFF
  analogSetAttenuation(ADC_11db);  // 0-3.3V range
}

int readMoisture() {
  // Power ON sensor
  digitalWrite(POWER_PIN, HIGH);
  delay(100);  // Let sensor stabilize

  // Read multiple samples for stability
  int sum = 0;
  for (int i = 0; i < 10; i++) {
    sum += analogRead(MOISTURE_PIN);
    delay(10);
  }
  int reading = sum / 10;

  // Power OFF sensor (prevents corrosion!)
  digitalWrite(POWER_PIN, LOW);

  return reading;
}

void loop() {
  int moisture = readMoisture();

  // Convert to percentage (calibrate these values!)
  int dryValue = 3200;   // ADC reading in dry soil
  int wetValue = 1200;   // ADC reading in wet soil

  int moisturePercent = map(moisture, dryValue, wetValue, 0, 100);
  moisturePercent = constrain(moisturePercent, 0, 100);

  Serial.printf("Moisture: %d%% (ADC: %d)\n", moisturePercent, moisture);

  delay(60000);  // Read every 60 seconds
}
```

## Calibration Process

**Step 1 - Dry reading:**
```cpp
// Insert sensor in completely DRY soil
// Record ADC value (e.g., 3200)
int dryValue = 3200;
```

**Step 2 - Wet reading:**
```cpp
// Insert sensor in water-SATURATED soil (not submerged in water!)
// Record ADC value (e.g., 1200)
int wetValue = 1200;
```

**Step 3 - Map to percentage:**
```cpp
int moisturePercent = map(reading, dryValue, wetValue, 0, 100);
```

## Capacitive vs Resistive

### Capacitive Sensor (Better)

**Advantages:**
- No exposed metal probes
- Resistant to corrosion
- Longer lifespan
- Can sense through plastic barrier

**Disadvantages:**
- More expensive (~$2-5)
- Slightly less sensitive

### Resistive Sensor (Cheaper)

**Advantages:**
- Very cheap (~$0.50-1)
- Simple design
- More sensitive

**Disadvantages:**
- Exposed metal probes corrode
- Shorter lifespan (months)
- Must use power switching!

**Recommendation:** Use capacitive if available. If resistive, MUST use power switching to prevent rapid corrosion.

## Key Features

**Analog output:**
- Voltage decreases as moisture increases
- Dry soil = HIGH voltage (~3V)
- Wet soil = LOW voltage (~0.5-1V)
- Read with ADC for percentage

**Digital output:**
- ON/OFF threshold trigger
- Adjustable via onboard potentiometer
- Can trigger relay/pump directly

## Gotchas

1. **Corrosion:** Resistive sensors corrode rapidly with constant power - use switching!
2. **Calibration drift:** Readings change over time as sensor degrades - recalibrate monthly
3. **Soil type:** Different soils (clay, sand, loam) give different readings
4. **Temperature:** Moisture readings affected by soil temperature
5. **Depth:** Insert to consistent depth for repeatable readings
6. **Fertilizer:** Salts in soil affect readings (resistive more than capacitive)

## Automated Watering Example

```cpp
#define MOISTURE_PIN 34
#define PUMP_PIN 26          // Relay/pump control
#define POWER_PIN 25

int dryThreshold = 30;  // Water when below 30% moisture

void loop() {
  int moisture = readMoisture();  // From previous example

  if (moisture < dryThreshold) {
    Serial.println("Soil dry - watering!");
    digitalWrite(PUMP_PIN, HIGH);  // Turn on pump
    delay(5000);  // Water for 5 seconds
    digitalWrite(PUMP_PIN, LOW);   // Turn off pump

    delay(300000);  // Wait 5 minutes before next check
  }

  delay(60000);  // Check every 60 seconds
}
```

## Sensor Placement

**Best practices:**
- Insert vertically near plant roots
- Consistent depth (5-10cm typical)
- Away from direct watering point
- Multiple sensors for large area
- Avoid rocks/debris in soil

## Applications

**Plant watering:** Automatic irrigation when soil gets dry.

**Greenhouse:** Monitor multiple zones with multiple sensors.

**Garden automation:** Water only areas that need it.

**Research:** Track soil moisture over time for farming data.

**Hydroponics:** Monitor growing medium moisture.

## Troubleshooting

**Readings don't change:**
- Sensor may be dead (corrosion)
- Check wiring (analog pin correct?)
- Verify power (VCC connected?)

**Erratic readings:**
- Poor soil contact
- Sensor corroding (use capacitive or power switching)
- Calibration drift (recalibrate)

**Always reads wet/dry:**
- Calibration values wrong
- Sensor damaged
- Check with multimeter (measure voltage directly)

## Maintenance

**Resistive sensors:**
- Replace every 3-6 months
- Clean probes monthly
- Use power switching always

**Capacitive sensors:**
- Can last years with proper care
- Wipe clean occasionally
- Still use power switching for best lifespan
