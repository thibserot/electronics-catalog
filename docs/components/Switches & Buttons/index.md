# Physical Switches & Buttons — SW100

Collection of mechanical switches and buttons for user input, power control, and mode selection. Includes keyboard switches, panel-mount buttons, toggle switches, and rocker switches for various project needs.

## Comparison

| Component | Type | Action | Size | Best For |
|-----------|------|--------|------|----------|

| [SW103](SW103.md) | Mini toggle | Latching SPDT | M6 panel mount | Power/mode selection |
| [SW104](SW104.md) | Push button | Momentary | 12mm panel | Simple triggers, reset |
| [SW105](SW105.md) | LED button | Latching/Momentary | 16mm panel | Illuminated controls |
| [SW106](SW106.md) | Rocker switch | Latching SPST | Panel mount (pre-wired) | Power switches |
| [SW107](SW107.md) | Rocker switch | Latching SPST | 10×15mm panel | Compact power control |

## Selection Guide

**[SW101](SW101.md):** MX-compatible mechanical switches for custom keyboard builds or tactile mechanical input where you want that distinctive keyboard feel.

**[SW102](SW102.md):** Assortment of 25 tact switch types in various SMD and DIP packages—perfect when you need a variety of sizes for PCB prototyping or repairs.

**[SW103](SW103.md):** Mini toggle switch (SPDT) with ON-ON or ON-OFF-ON variants for selecting between two states or modes.

**[SW104](SW104.md):** Pre-wired 12mm momentary pushbutton for simple panel-mount triggers, reset buttons, or user input without soldering.

**[SW105](SW105.md):** 16mm illuminated pushbutton with integrated LED ring—ideal for power buttons or status-indicated controls that need visual feedback.

**[SW106](SW106.md):** Pre-wired mini rocker switch for quick panel-mount power switching without soldering connections.

**[SW107](SW107.md):** Compact 10×15mm SPST rocker switch for tight panel spaces where you need simple on/off control.

## Common Applications

**Keyboard builds:** Use SW101 MX mechanical switches with custom keycaps and matrix wiring for DIY keyboards or macro pads.

**PCB prototyping:** Use SW102 tact switch assortment for adding buttons directly to custom PCBs in various footprints.

**Power control:** Use SW103 toggle, SW106, or SW107 rocker switches in the power line to manually enable/disable DC loads (fans, LED strips, modules).

**Mode selection:** Use SW103 toggle switch (ON-OFF-ON) to select between two operating modes or circuit paths.

**User input:** Use SW104 momentary button or SW105 LED button for reset, trigger, or control inputs that need clear tactile feedback.

**Status indication:** Use SW105 LED button when you need both switching capability and visual feedback (power on/off, active mode, etc.).
