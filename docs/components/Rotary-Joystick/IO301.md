# KY-040 Rotary Encoder with Push Button - IO301

Incremental rotary encoder module based on EC11 encoder. Detects clockwise/counter-clockwise rotation through quadrature output and includes integrated push button. Perfect for volume controls, menu navigation, and settings adjustment.

## Key Specifications

| Parameter | Value |
|-----------|-------|
| **Encoder type** | EC11 (mechanical, incremental) |
| **Steps per revolution** | 20 (with detents) |
| **Output type** | Quadrature (A/B channels) |
| **Push button** | Integrated (normally open) |
| **Supply voltage** | 5V (module), 3.3V compatible outputs |
| **Rotation** | 360° continuous (no stops) |
| **Lifespan** | ~30,000 rotations typical |

## How It Works

**Quadrature encoding:**
- Two output channels (A and B) with 90° phase shift
- Both channels produce square waves when rotating
- Direction determined by which channel leads:
  - **CW:** A leads B (A rises before B)
  - **CCW:** B leads A (B rises before A)
- 20 detents per full rotation = 20 "clicks"

**Detent positions:**
- Physical clicks you feel when turning
- Encoder settles at stable positions between transitions
- Most reliable to read on falling edge of CLK

## Pinout

```
KY-040 Module
    ___
   |   |
   | ⟳ |  Encoder
   |___|
   | | | | |
   G V S C D
   N C W L T
   D C   K

GND = Ground
VCC = Power (5V, module has 5V→3.3V level shifting)
SW  = Switch (button press, active LOW)
CLK = Clock output (Channel A)
DT  = Data output (Channel B)
```

**Module features:**
- Built-in pull-up resistors (10kΩ) on all outputs
- Can connect directly to 3.3V or 5V microcontrollers
- No external components needed

## Typical Wiring (ESP32)

```
ESP32           KY-040
-----           ------
5V     -------> VCC (or use 3.3V)
GND    -------> GND
GPIO25 -------> CLK (Channel A)
GPIO26 -------> DT  (Channel B)
GPIO27 -------> SW  (Button, optional)
```

**Important:** Use interrupt-capable GPIO pins for CLK and DT for reliable operation.

## Example Code (ESP32)

```cpp
// ESP32 + KY-040 Rotary Encoder
#define CLK_PIN 25   // Channel A (must support interrupts)
#define DT_PIN  26   // Channel B
#define SW_PIN  27   // Button (optional)

volatile int encoderPos = 0;
volatile bool buttonPressed = false;

void IRAM_ATTR handleEncoder() {
  // Read both pins immediately
  int clkState = digitalRead(CLK_PIN);
  int dtState = digitalRead(DT_PIN);

  // Determine direction
  if (clkState == LOW) {  // CLK falling edge (detent position)
    if (dtState == HIGH) {
      encoderPos++;  // Clockwise
    } else {
      encoderPos--;  // Counter-clockwise
    }
  }
}

void IRAM_ATTR handleButton() {
  buttonPressed = true;
}

void setup() {
  Serial.begin(115200);

  pinMode(CLK_PIN, INPUT);
  pinMode(DT_PIN, INPUT);
  pinMode(SW_PIN, INPUT_PULLUP);

  // Attach interrupts
  attachInterrupt(digitalPinToInterrupt(CLK_PIN), handleEncoder, FALLING);
  attachInterrupt(digitalPinToInterrupt(SW_PIN), handleButton, FALLING);
}

void loop() {
  static int lastPos = 0;

  // Check for position changes
  if (encoderPos != lastPos) {
    Serial.printf("Position: %d (change: %+d)\n",
                  encoderPos, encoderPos - lastPos);
    lastPos = encoderPos;
  }

  // Check button press
  if (buttonPressed) {
    Serial.println("Button pressed!");
    buttonPressed = false;
    delay(200);  // Debounce
  }

  delay(50);
}
```

## Advanced: Debouncing

Mechanical encoders can produce noisy signals. Add debouncing for cleaner reading:

```cpp
void IRAM_ATTR handleEncoder() {
  static unsigned long lastInterruptTime = 0;
  unsigned long interruptTime = millis();

  // Debounce: ignore if < 5ms since last change
  if (interruptTime - lastInterruptTime > 5) {
    int clkState = digitalRead(CLK_PIN);
    int dtState = digitalRead(DT_PIN);

    if (clkState == LOW) {
      if (dtState == HIGH) {
        encoderPos++;
      } else {
        encoderPos--;
      }
    }
  }

  lastInterruptTime = interruptTime;
}
```

## Volume Control Example

```cpp
#define MAX_VOLUME 100
#define MIN_VOLUME 0

int volume = 50;  // Start at 50%

void loop() {
  static int lastPos = 0;

  if (encoderPos != lastPos) {
    int change = encoderPos - lastPos;
    volume = constrain(volume + change, MIN_VOLUME, MAX_VOLUME);

    Serial.printf("Volume: %d%%\n", volume);
    lastPos = encoderPos;
  }

  delay(50);
}
```

## Menu Navigation Example

```cpp
const char* menuItems[] = {"Home", "Settings", "About", "Exit"};
const int menuSize = 4;
int menuIndex = 0;

void loop() {
  static int lastPos = 0;

  if (encoderPos != lastPos) {
    int change = encoderPos - lastPos;
    menuIndex = (menuIndex + change + menuSize) % menuSize;

    Serial.printf("Selected: %s\n", menuItems[menuIndex]);
    lastPos = encoderPos;
  }

  if (buttonPressed) {
    Serial.printf("Confirmed: %s\n", menuItems[menuIndex]);
    buttonPressed = false;
    delay(200);
  }

  delay(50);
}
```

## Gotchas

1. **Interrupt required:** Polling is unreliable - always use interrupts on CLK pin
2. **Read both pins:** Must read CLK and DT together to determine direction
3. **Debouncing needed:** Mechanical contacts bounce - add software debounce
4. **Fast rotation:** Very fast spinning can skip steps if ISR too slow
5. **No absolute position:** Encoder only tracks relative changes (incremental)
6. **Module polarity:** Some modules reverse CW/CCW - may need to swap CLK/DT
7. **Button bouncing:** SW pin also needs debouncing for clean presses

## Troubleshooting

**Position jumps erratically:**
- Add debouncing (5-10ms minimum)
- Check for loose connections
- Verify both CLK and DT are connected
- Use interrupt on CLK pin, not polling

**Wrong rotation direction:**
- Swap CLK and DT pin assignments
- Or invert increment/decrement logic

**Missing steps during fast rotation:**
- ISR may be too slow (simplify interrupt code)
- Hardware issue (encoder worn out)
- Check for loose shaft/knob

**Button doesn't work:**
- Verify pull-up enabled (or use external 10kΩ)
- Check active LOW logic (pressed = LOW)
- Add debounce delay

## EC11 Encoder Specifications

**Mechanical:**
- Shaft diameter: 6mm (knurled or smooth)
- Shaft length: 15mm typical
- Mounting: Panel-mount or PCB-mount
- Rotation: Continuous 360° (no end stops)

**Electrical:**
- Detents: 20 or 30 per revolution (20 most common)
- Contact resistance: <50Ω
- Insulation resistance: >100MΩ
- Rated current: 10mA max

**Capacitive touch slider:**
- No moving parts
- Less intuitive (no tactile feedback)
- Modern aesthetic

**Buttons (up/down):**
- Cheaper
- Less intuitive UX
- No continuous rotation
