# TB6612 Dual Motor Driver Module (1.2A per channel) - AC101

Compact dual H-bridge motor driver module based on the Toshiba TB6612FNG IC. More efficient than L293D with lower voltage drop and higher current capacity.

## Key Specifications

| Parameter | Value |
|-----------|-------|
| **Chip** | Toshiba TB6612FNG |
| **Channels** | 2 independent H-bridges |
| **Motor voltage** | 2.7V - 5.5V (VM) |
| **Logic voltage** | 2.7V - 5.5V (VCC) |
| **Current per channel** | 1.2A continuous, 3.2A peak (short duration) |
| **PWM frequency** | Up to 100kHz |
| **Voltage drop** | ~0.5V (much better than L293D's ~2V) |
| **Package** | Breakout module with screw terminals |
| **Dimensions** | ~26 x 20mm |

## Pinout

### Power Pins

- **VM**: Motor power supply (2.7-5.5V)
- **VCC**: Logic power supply (2.7-5.5V), can be same as VM
- **GND**: Common ground
- **PWMA/PWMB**: PWM input for speed control (or tie high for full speed)
- **STBY**: Standby pin (pull high to enable, low to disable all outputs)

### Motor A Control

- **AIN1, AIN2**: Direction control for Motor A
- **AO1, AO2**: Motor A output terminals

### Motor B Control

- **BIN1, BIN2**: Direction control for Motor B
- **BO1, BO2**: Motor B output terminals

## Truth Table

| IN1 | IN2 | PWM | Motor |
|-----|-----|-----|-------|
| H | L | H | Forward |
| L | H | H | Reverse |
| L | L | H | Brake (short brake) |
| H/L | H/L | L | Stop (coast) |

## Typical Wiring (ESP32)

```cpp
// Motor A
#define PWMA  25
#define AIN1  26
#define AIN2  27

// Motor B
#define PWMB  32
#define BIN1  33
#define BIN2  14

// Standby
#define STBY  13

void setup() {
  pinMode(PWMA, OUTPUT);
  pinMode(AIN1, OUTPUT);
  pinMode(AIN2, OUTPUT);
  pinMode(PWMB, OUTPUT);
  pinMode(BIN1, OUTPUT);
  pinMode(BIN2, OUTPUT);
  pinMode(STBY, OUTPUT);

  digitalWrite(STBY, HIGH); // Enable driver

  // Setup PWM channels
  ledcSetup(0, 5000, 8);  // Channel 0, 5kHz, 8-bit
  ledcAttachPin(PWMA, 0);
  ledcSetup(1, 5000, 8);  // Channel 1, 5kHz, 8-bit
  ledcAttachPin(PWMB, 1);
}

void motorA_forward(uint8_t speed) {
  digitalWrite(AIN1, HIGH);
  digitalWrite(AIN2, LOW);
  ledcWrite(0, speed);
}

void motorA_reverse(uint8_t speed) {
  digitalWrite(AIN1, LOW);
  digitalWrite(AIN2, HIGH);
  ledcWrite(0, speed);
}

void motorA_brake() {
  digitalWrite(AIN1, LOW);
  digitalWrite(AIN2, LOW);
  ledcWrite(0, 255);
}

void motorA_stop() {
  ledcWrite(0, 0);
}
```

## Key Features

**Advantages over L293D:**

- Much lower voltage drop (~0.5V vs ~2V)
- Higher efficiency (less heat)
- Higher current capacity (1.2A vs 600mA)
- Faster switching for smoother PWM

**Standby mode:** Pull STBY low to disable all outputs and save power.

**Independent channels:** Control two motors independently or combine for higher current (single motor).

## Gotchas

1. **VM voltage:** Limited to 5.5V max (cannot drive 12V motors)
2. **Current limit:** 1.2A continuous - check motor stall current
3. **STBY pin:** Must be HIGH to enable outputs (can tie to VCC if always-on needed)
4. **PWM frequency:** Keep PWM under 100kHz to avoid driver issues
5. **Separate power:** Use separate supply for VM if motors draw significant current

## Compatible Motors

Good for:

- N20 gear motors (6V or less)
- 716 coreless motors (3.7-4.2V)
- Small DC motors under 1A stall current
- Servo hack motors (continuous rotation)

**Not suitable for:**

- 12V fans or motors
- High-current motors (>1.2A continuous)
- Stepper motors (needs different driver)
