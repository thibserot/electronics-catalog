# 5V 3A Buck Converter (Fixed 5V) — PS102

**Topology:** Buck (step-down)
**Output:** Fixed 5V

## Description

Compact DC-DC buck converter module for stepping down 5-30V to fixed 5V output. Commonly used for powering 5V microcontrollers and devices from higher voltage sources like 12V automotive supplies or wall adapters.

## Specifications

- **Input voltage:** 5-30V (must be higher than output; preferably ≤28V)
- **Output voltage:** Fixed 5V
- **Output current:** 3A max (sustained ~1.6-1.8A without heatsink)
- **Conversion efficiency:** Up to 96%
- **Output ripple:** <30mV
- **Output accuracy:** ±0.1V
- **No-load current:** <1mA
- **Operating temperature:** -40°C to +85°C
- **Module size:** 17 × 12 × 4mm

## Wiring Notes

- **VIN:** Input positive (5-30V)
- **GND:** Common ground
- **VOUT:** Output positive (5V)
- Add heatsinking for sustained loads above 1.8A
- Use input and output capacitors (typically 10-100µF) for stable operation
