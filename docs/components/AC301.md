# IRLZ44N N-Channel Power MOSFET (Logic-Level, TO-220) - AC301

Logic-level N-channel power MOSFET in TO-220 package. Perfect for switching high-current loads (motors, LEDs, solenoids) directly from 3.3V or 5V microcontroller GPIO pins.

## Key Specifications

| Parameter | Value |
|-----------|-------|
| **Package** | TO-220 (through-hole) |
| **Type** | N-Channel Enhancement Mode |
| **V_DS (Drain-Source)** | 55V max |
| **I_D (Continuous Drain)** | 47A @ 25°C, 30A @ 100°C |
| **I_D (Pulsed)** | 190A |
| **R_DS(on)** | 22mΩ @ V_GS = 5V, 35mΩ @ V_GS = 3.3V |
| **V_GS(th)** | 1-2V (logic-level) |
| **Gate voltage** | ±20V max |
| **Power dissipation** | 94W @ 25°C (derate with temperature) |
| **Switching speed** | ~10kHz (with proper gate drive) |
| **Quantity** | 10 pieces |

## Pinout (TO-220)

```
   Front view (facing flat side)

    +-----+
    | 1 2 3 |
    +-----+
     | | |
     G D S

1 = Gate (G)
2 = Drain (D)
3 = Source (S)
```

**Gate (G):** Control pin - connect to GPIO via 100-220Ω resistor

**Drain (D):** Connect to load (motor, LED strip, solenoid, etc.)

**Source (S):** Connect to ground (GND)

## Typical Wiring (Low-Side Switch)

```
+VCC (12V, 24V, etc.)
  |
  +--- Load (motor, solenoid, LED strip) ---+
                                             |
                                        Drain (D)
                                       IRLZ44N
GPIO --- 220Ω ------- Gate (G)
                                       Source (S)
                                             |
                                            GND
```

**Flyback diode (for inductive loads):** Add 1N4007 or similar across load (cathode to +VCC, anode to drain).

## Example Code (ESP32)

```cpp
// MOSFET control pin
#define MOSFET_PIN 25

void setup() {
  pinMode(MOSFET_PIN, OUTPUT);
  digitalWrite(MOSFET_PIN, LOW);  // Start with load OFF
}

void load_on() {
  digitalWrite(MOSFET_PIN, HIGH);  // 3.3V turns MOSFET fully on
}

void load_off() {
  digitalWrite(MOSFET_PIN, LOW);   // 0V turns MOSFET off
}

// PWM dimming for LEDs
void load_pwm(uint8_t duty) {
  ledcSetup(0, 5000, 8);  // 5kHz, 8-bit
  ledcAttachPin(MOSFET_PIN, 0);
  ledcWrite(0, duty);  // 0-255
}
```

## Features

**Logic-level gate:** Fully turns on with 3.3V or 5V (no separate gate driver needed).

**Low R_DS(on):** Only 22mΩ when fully on - minimal voltage drop and heat.

**High current:** Can handle 30-47A continuous (with heatsink).

**Fast switching:** Suitable for PWM up to ~10kHz.

## Gotchas

1. **Gate resistor required:** Use 100-220Ω resistor between GPIO and gate to limit inrush current
2. **Pull-down resistor:** Add 10kΩ resistor from gate to source to ensure MOSFET stays off when GPIO is floating (startup/reset)
3. **Flyback diode:** MUST use with inductive loads (motors, solenoids, relays) to protect MOSFET
4. **Heatsinking:** Required for currents >10A continuous
5. **Low-side only:** This wiring works only for low-side switching (load between +VCC and drain)
6. **ESD sensitive:** Handle carefully, avoid static discharge to gate pin

## Heatsinking Requirements

| Current | Heatsink | Notes |
|---------|----------|-------|
| <5A | None | MOSFET stays cool |
| 5-15A | Small clip-on | Recommended |
| 15-30A | Medium-to-large | Required |
| >30A | Large with fan | Required, thermal paste |

**Thermal calculation:** P_dissipated = I^2 × R_DS(on)

Example: 20A load → P = 20² × 0.022 = 8.8W (needs heatsink)

## Typical Applications

**LED strips:** Switch 12V/24V high-power LED strips (10-30A)

**Motors:** Control DC motors, fans, pumps (with flyback diode)

**Solenoids:** AC011 solenoid valve, AC005 electromagnetic lock

**Heaters:** 12V heating elements

**Relays:** Trigger relay coils from low-voltage logic

## Protection Circuits

**Gate protection:**

- 220Ω resistor (current limiting)
- 10kΩ pull-down (prevents floating gate)
- Optional zener diode (12V or 15V) for overvoltage protection

**Load protection:**

- Flyback diode for inductive loads (1N4007, 1N5819)
- Fuse in series with load for overcurrent protection

## Advantages vs Relays

**MOSFET (AC301):**

- Silent operation
- Fast switching (kHz range)
- No contact bounce
- Long lifespan (millions of cycles)
- PWM capable

**Relay (AC008):**

- Complete electrical isolation
- Can switch AC loads
- Higher voltage/current capability
- Easier to understand

## Compatible Loads

**Good for:**

- 12V/24V DC motors
- LED strips (5-30A)
- Solenoids, valves
- Heating elements
- DC fans

**Not suitable for:**

- AC loads (need relay or SSR)
- High-side switching (need P-channel MOSFET)
- Very high frequency PWM (>20kHz)
