# Ball Tilt Switch Module - IO404

Simple mechanical tilt sensor with metal ball inside. When tilted, ball rolls and completes circuit. Perfect for basic tilt/orientation detection without any code complexity.

## Key Specifications

| Parameter | Value |
|-----------|-------|
| **Type** | Mechanical switch (rolling ball) |
| **Output** | Digital (ON/OFF) |
| **Tilt angle** | ~15-30° (varies by model) |
| **Supply voltage** | 3.3V - 5V |
| **Operating temp** | -25°C to +70°C |
| **Lifespan** | ~100,000 cycles |
| **Response time** | <10ms |

## How It Works

**Internal structure:**
- Hollow metal cylinder with conductive pins at one end
- Small metal ball inside
- When upright: Ball at bottom, bridges pins → CLOSED
- When tilted: Ball rolls away, breaks contact → OPEN
- Or reverse: normally open, closes when tilted (depends on model)

**Two types:**
1. **Normally closed:** Closed when upright, opens when tilted
2. **Normally open:** Opens when upright, closes when tilted

Check your module to determine type!

## Example Code (ESP32)

```cpp
// ESP32 + Tilt Switch
#define TILT_PIN 25

void setup() {
  Serial.begin(115200);
  pinMode(TILT_PIN, INPUT);
}

void loop() {
  int tiltState = digitalRead(TILT_PIN);

  if (tiltState == HIGH) {
    Serial.println("TILTED!");
  } else {
    Serial.println("Upright");
  }

  delay(500);
}
```

## Debouncing

Ball bounces when rolling - add debouncing:

```cpp
#define TILT_PIN 25

bool isTilted() {
  int reading1 = digitalRead(TILT_PIN);
  delay(20);  // Wait for bounce to settle
  int reading2 = digitalRead(TILT_PIN);

  return (reading1 == reading2) ? reading1 : false;
}

void loop() {
  if (isTilted()) {
    Serial.println("TILTED!");
  }
  delay(500);
}
```

## Detect Tilt Event (Not Continuous)

```cpp
#define TILT_PIN 25

int lastState = LOW;

void loop() {
  int currentState = digitalRead(TILT_PIN);

  // Detect rising edge (upright → tilted)
  if (currentState == HIGH && lastState == LOW) {
    Serial.println("Just tilted!");
  }

  // Detect falling edge (tilted → upright)
  if (currentState == LOW && lastState == HIGH) {
    Serial.println("Returned to upright!");
  }

  lastState = currentState;
  delay(50);
}
```

## Alarm Example

```cpp
#define TILT_PIN 25
#define BUZZER_PIN 26

void loop() {
  if (digitalRead(TILT_PIN) == HIGH) {
    // Object tilted - activate alarm!
    digitalWrite(BUZZER_PIN, HIGH);
    Serial.println("ALARM: Tilted!");
  } else {
    digitalWrite(BUZZER_PIN, LOW);
  }

  delay(100);
}
```

## Key Features

**Simple mechanical switch:**
- No ADC needed (digital only)
- No calibration required
- No complex code

**No power when unused:**
- Mechanical switch (no current draw)
- Only module pull-up/LED uses power
- Perfect for battery devices

**Fast response:**
- <10ms switching time
- Instant detection
- No processing delay

## Gotchas

1. **Orientation dependent:** Must mount in correct orientation (test first)
2. **Not precise:** Cannot measure exact angle (just ON/OFF)
3. **Bouncing:** Ball bounces when rolling - debounce required
4. **Wear out:** Mechanical contacts degrade over time (~100k cycles)
5. **Vibration sensitivity:** May trigger from vibration, not just tilt
6. **Polarity varies:** Some modules inverted (HIGH = upright, LOW = tilted)

## When to Use

**Good for:**
- Simple tilt ON/OFF detection
- Low-cost projects
- Battery devices (low power)
- Learning/prototyping
- Orientation-specific triggers

**NOT good for:**
- Precise angle measurement (use accelerometer)
- Continuous tilt monitoring (use gyro/accel)
- High reliability (mechanical wear)
- Vibration-prone environments

## Comparison with Accelerometer

| Feature | Tilt Switch (IO404) | Accelerometer (IO402) |
|---------|--------------------|-----------------------|
| **Output** | Digital (ON/OFF) | Analog (continuous) |
| **Precision** | Low (±15°) | High (0.1° possible) |
| **Code complexity** | Trivial | Moderate |
| **Price** | $0.20-0.50 | $2-3 |
| **Power** | <1mA | ~40μA |
| **Axes** | 1 (single direction) | 3 (X, Y, Z) |

**Use tilt switch when:**
- Only need simple ON/OFF
- Budget constrained
- Code simplicity important

**Use accelerometer when:**
- Need precise angles
- Multi-axis tilt needed
- Continuous monitoring required

## Applications

**Anti-theft alarm:** Detect when object moved/tilted.

**Picture frame orientation:** Auto-rotate display based on tilt.

**Earthquake detector:** Simple seismic sensor (low sensitivity).

**Parking sensor:** Detect car on slope.

**Toy/game controllers:** Simple tilt control for games.

**Drawer/door sensor:** Detect when opened (alternative to magnetic reed).

## Troubleshooting

**Always reads same state:**
- Check wiring (SIG connected?)
- Module may be dead
- Wrong orientation (flip module over)

**Constantly switching:**
- Ball bouncing (add debouncing)
- Vibration triggering sensor
- Mount more securely

**Opposite logic (HIGH when should be LOW):**
- Normal - modules vary
- Invert logic in code (use `!` operator)
