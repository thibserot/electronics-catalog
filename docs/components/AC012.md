# 12V DC Solenoid Valve 1/2" (Normally Closed) - AC012

Electrically-controlled water valve with 1/2" (DN15) threaded connections. Normally closed design - opens when 12V DC is applied, closes when power is removed.

## Key Specifications

| Parameter | Value |
|-----------|-------|
| **Voltage** | 12V DC |
| **Current** | ~300-500mA (coil) |
| **Power** | ~5-6W |
| **Connection size** | 1/2" NPT or G1/2" (check marking) |
| **Port type** | 2-way, normally closed (NC) |
| **Pressure rating** | 0-0.8 MPa (0-116 PSI) |
| **Flow direction** | Marked with arrow on body |
| **Media** | Water, air, non-corrosive liquids |
| **Temperature** | 0-80°C (liquid temp) |
| **Body material** | Brass or plastic (check specs) |
| **Seal material** | NBR (nitrile rubber) |
| **Quantity** | 4 pieces |

## Pinout / Connections

**Electrical (coil):**

- 2 wire leads (red/black or unmarked)
- **Polarity:** Not sensitive (DC coil, either direction works)

**Plumbing:**

- **Inlet**: Marked with arrow (flow direction)
- **Outlet**: Opposite side
- **Threading**: 1/2" male NPT or G1/2" threads

## Operation

**Normally Closed (NC):**

- Power OFF → Valve closed (no flow)
- Power ON (12V DC) → Valve opens (allows flow)
- Spring returns valve to closed position when power removed

## Typical Wiring (with MOSFET)

```
+12V
  |
  +--- Solenoid Coil ---|>|--- +
                               |
                          Drain (D)
                        IRLZ44N (AC301)
ESP32 GPIO ---[220Ω]--- Gate (G)

10kΓ                   Source (S)
  |                         |
GND ----------------------GND

Diode: 1N4007 or 1N5819 (flyback protection - REQUIRED!)
```

**Never connect solenoid directly to GPIO** - use relay (AC008) or MOSFET (AC301).

## Example Code (ESP32 + MOSFET)

```cpp
// Solenoid control via MOSFET
#define VALVE_PIN 25

void setup() {
  pinMode(VALVE_PIN, OUTPUT);
  digitalWrite(VALVE_PIN, LOW);  // Valve closed initially
}

void valve_open() {
  digitalWrite(VALVE_PIN, HIGH);  // Apply 12V
}

void valve_close() {
  digitalWrite(VALVE_PIN, LOW);   // Remove power
}

// Timed watering example
void water_for(unsigned long milliseconds) {
  valve_open();
  delay(milliseconds);
  valve_close();
}
```

## Plumbing Installation

**Threading:**

1. Wrap threads with PTFE tape (Teflon tape) - 3-5 wraps clockwise
2. Hand-tighten into fitting
3. Use wrench for final 1-2 turns (don't overtighten)

**Flow direction:** Arrow on valve body shows correct flow direction (inlet → outlet).

**Pressure:** Requires minimum pressure (0.02-0.05 MPa) to seal properly. Won't work well with gravity-fed systems at very low pressure.

## Gotchas

1. **Flyback diode required:** MUST use 1N4007 or similar across coil to protect MOSFET/relay
2. **Inrush current:** Initial energizing can spike to 1A briefly
3. **Minimum pressure:** Needs some water pressure to seal - may leak at very low pressure
4. **Flow direction:** Install with arrow pointing from inlet to outlet
5. **Power consumption:** Coil draws 300-500mA continuously when open (not suitable for battery operation)
6. **Thread type:** Check if NPT or G-thread (may need adapter)
7. **Water hammer:** Closing valve quickly can cause pressure spike in pipes

## Power Options

**12V power supply:**

- Wall adapter (1A or higher)
- Car battery
- 3S LiPo battery (11.1-12.6V)
- Lead-acid battery

**NOT suitable for:**

- 5V USB power (voltage too low)
- Small batteries (current draw too high)

## Example Project: Smart Irrigation

```cpp
// Soil moisture sensor + solenoid valve
#define MOISTURE_PIN 34   // Analog input
#define VALVE_PIN    25   // Solenoid control

void loop() {
  int moisture = analogRead(MOISTURE_PIN);

  // If soil is dry (reading < 1000), water for 10 seconds
  if (moisture < 1000) {
    digitalWrite(VALVE_PIN, HIGH);  // Open valve
    delay(10000);                   // Water for 10s
    digitalWrite(VALVE_PIN, LOW);   // Close valve
    delay(3600000);                 // Wait 1 hour before checking again
  }

  delay(60000);  // Check every minute
}
```

## Compatible Components

**Drivers:**

- AC301 (IRLZ44N MOSFET) - recommended for direct control
- AC008 (1-Channel Relay) - for electrical isolation

**Sensors:**

- ENV401 (Soil Moisture Sensor) - for automated irrigation
- AC013 (Water Pressure Sensor) - to monitor system pressure

**Fittings:**

- 1/2" NPT or G1/2" adapters, couplings, barbs

## Safety Notes

- **Pressure rating:** Do not exceed 0.8 MPa (116 PSI)
- **Liquid compatibility:** Use only with water or compatible non-corrosive liquids
- **Temperature:** Keep liquid temperature 0-80°C
- **Freezing:** Drain valve if risk of freezing (ice can damage valve)
- **Electrical:** Ensure proper insulation of wire connections (waterproof if outdoor)
