# Active Buzzer - AC805

A self-oscillating electromagnetic buzzer that produces a fixed-frequency tone when powered. Unlike passive buzzers, active buzzers have built-in oscillator circuits and only need DC voltage to sound - no PWM required. Perfect for simple alerts, alarms, and notification beeps where you just need a consistent tone.

## Key Differences: Active vs Passive

**Active Buzzer (this component):**
- Has built-in oscillator
- Apply DC voltage = instant beep at fixed frequency
- Cannot change tone/frequency
- Simpler to use (no PWM needed)

**Passive Buzzer (AC803):**
- No oscillator - needs external square wave (PWM)
- Can generate different tones/melodies
- More versatile but requires PWM control

## Specifications

- **Type:** Active (self-oscillating)
- **Operating Voltage:** 3-5V DC (typical)
- **Current:** 20-30mA typical
- **Sound Output:** 80-95 dB @ 10cm
- **Frequency:** Fixed (typically 2-4 kHz, varies by model)
- **Package:** 12mm diameter typical (cylindrical can)

## Identifying Active vs Passive

- **Active:** Usually has sticker/tape on top, often sealed
- **Passive:** Can see circuit board through opening on back
- **Test:** Apply 3-5V DC - active will beep, passive will be silent

## Wiring

**Direct drive (low current buzzers, <30mA):**

```
ESP32 GPIO → Active Buzzer (+) → GND
```

Note: Most ESP32 GPIOs can source/sink 20-30mA, suitable for most active buzzers.

**Transistor drive (safer, recommended for higher current):**

```
ESP32 GPIO → 1kΩ → NPN Base (e.g., 2N2222)
NPN Emitter → GND
Buzzer (+) → NPN Collector
Buzzer (-) → GND
VCC (3-5V) → Buzzer (+)
```

## Polarity

- **Longer leg:** Positive (+)
- **Shorter leg:** Negative (-)
- **PCB marking:** Usually marked with + symbol

Some module boards are polarity-protected and have 3 pins (VCC, GND, I/O).

## Gotchas

- **Fixed frequency only** - cannot play melodies or change tone
- **Can be loud** - may need to muffle if too annoying during development
- **Check voltage rating** - some are 3V, others 5V, many work with both
- **Current draw** - typically 20-30mA, verify your GPIO can handle it
- **Polarity matters** - reverse voltage won't damage most buzzers but won't sound

## How to use

**Simple beep on ESP32:**

```cpp
const int BUZZER_PIN = 2;  // any GPIO

void setup() {
  pinMode(BUZZER_PIN, OUTPUT);
  digitalWrite(BUZZER_PIN, LOW);  // ensure off
}

void beep(int duration_ms) {
  digitalWrite(BUZZER_PIN, HIGH);
  delay(duration_ms);
  digitalWrite(BUZZER_PIN, LOW);
}

void loop() {
  beep(200);  // 200ms beep
  delay(1000);
}
```

**Double beep notification:**

```cpp
const int BUZZER_PIN = 2;

void setup() {
  pinMode(BUZZER_PIN, OUTPUT);
}

void doubleBeep() {
  digitalWrite(BUZZER_PIN, HIGH);
  delay(100);
  digitalWrite(BUZZER_PIN, LOW);
  delay(100);
  digitalWrite(BUZZER_PIN, HIGH);
  delay(100);
  digitalWrite(BUZZER_PIN, LOW);
}

void loop() {
  doubleBeep();
  delay(2000);
}
```

**Alarm pattern:**

```cpp
const int BUZZER_PIN = 2;

void setup() {
  pinMode(BUZZER_PIN, OUTPUT);
}

void alarm(int cycles) {
  for (int i = 0; i < cycles; i++) {
    digitalWrite(BUZZER_PIN, HIGH);
    delay(200);
    digitalWrite(BUZZER_PIN, LOW);
    delay(200);
  }
}

void loop() {
  alarm(5);  // 5 beeps
  delay(3000);
}
```
