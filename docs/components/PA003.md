# High-Frequency Low-ESR Electrolytic Capacitor Kit (24 values) — PA003

391-piece, 24-value **high-frequency / low-ESR** aluminium electrolytic capacitor kit.
Low impedance makes these the right choice near switching regulators and on HF rails,
where the general-purpose kit (**PA008**) would run hot. Note the **400 V** values for
mains-side / high-voltage smoothing. Polarised — mind orientation.

## Notes
- **Low ESR vs general purpose:** prefer these (or PA008's higher-voltage parts) right at a buck/boost output and on noisy supply rails. See also **PA002** ferrite beads for HF supply filtering.
- **Polarity:** stripe = **negative** lead, longer lead = **+**.
- **400 V parts** are for mains-rectified / high-voltage rails only — overkill (and physically large) on logic supplies.
