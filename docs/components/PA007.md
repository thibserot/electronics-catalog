# Ceramic Capacitor Kit (10 values) — PA007

300-piece, 10-value multilayer/disc ceramic capacitor kit (box code **A19**).
Small-value caps for decoupling, crystal load caps, RC timing and filtering.

- **Max voltage:** 50 V
- **Material:** Ceramic
- **Lead spacing:** 5.08 mm
- **Quantity:** 30 pcs per value (300 total)

## Notes
- **Code reading:** first two digits = significant figures, third = number of zeros, result in **pF**. e.g. `104` = 10 + 4 zeros = 100000 pF = 100 nF.
- **100 nF (104)** is the everyday MCU decoupling cap — one across every VCC/GND pin pair.
- 10–68 pF values are typical **crystal load caps** for 8/16 MHz crystals.
