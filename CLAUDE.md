# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

A Git-versioned electronics catalog built with MkDocs Material. Each electronic component gets:
- A 1-2 page Markdown sheet (pinout, specs, wiring notes, gotchas)
- A short URL via GitHub Pages (e.g., `https://thibserot.github.io/electronics-catalog/TS001/`)
- Printable QR sticker generated from metadata (384px width, T02 mini printer friendly)
- Tag-based navigation across categories (e.g., `/tags/temperature/`)

## Common Commands

```bash
# Development workflow
make registry_stickers    # Generate ID registry YAML + stickers/QR (required before serve/publish)
make serve                # Build and preview at http://127.0.0.1:8000
make publish              # Build and deploy to GitHub Pages (gh-deploy --force)

# Individual steps (usually run via make)
python scripts/generate_id_registry.py        # Scan components, generate registry YAML
python scripts/build_registry_page.py         # Build registry page from YAML
python scripts/build_labels.py                # Generate QR stickers for all components

# Git hooks
make precommit-install    # Install pre-commit hook that auto-runs make registry_stickers
./scripts/install-git-hooks.sh   # Direct installation

# Python dependencies (requires virtualenv)
pip install mkdocs mkdocs-material qrcode pillow pyyaml
```

## Architecture

### ID System

Components use `CCNNN` IDs where `CC` = 2-letter category, `NNN` = 3-digit number:
- **TS**: Temperature sensors (DS18B20, PT100, MAX31865)
- **ENV**: Environmental sensors (BME280, SHT4x, TSL2561)
- **PS**: Power supplies/chargers/regulators (buck, LDO, TP4056)
- **MC**: Microcontrollers / dev boards (ESP32, RP2040)
- **RF**: Radios / comms (LoRa, nRF24, ESP-Now)
- **IO**: I/O expanders / ADC / DAC / level shifting
- **AC**: Actuators (fans, motors, servos, relays, MOSFET boards)
- **CN**: Connectors / cables / adapters
- **PA**: Passive components (resistors, capacitors, trim pots)
- **SW**: Switches & Buttons
- **OT**: Other / misc

**Family anchors**: `CCXX00` IDs (e.g., `PS200`, `AC200`) mark subcategories when the component file is `index.md`. For example:
- `docs/components/DC-DC Converter/index.md` → ID `PS000` (anchor for DC-DC converters)
- `docs/components/Bipolar Junction Transistor/index.md` → ID `AC200` (anchor for BJT transistors)

The scripts recognize anchors only when `number % 100 == 0` AND the file is `index.md`.

### Component Front-Matter

Every component page requires YAML front-matter:

```yaml
---
id: TS001                # Short code for URL & sticker
name: DS18B20            # Title shown in navigation
category: TS             # Category code
tags: [sensor, temperature, 1-wire, digital]
short: "±0.5°C • 3.0–5.5V"     # 1-line spec for sticker
use: "Temperature"             # Brief use description
# Optional overrides:
title: DS18B20           # Override page title (defaults to name)
qr_url: https://...      # Override QR URL (defaults to GitHub Pages URL)
no_label: true           # Skip sticker generation for this component
---
```

**Optional printer metadata** (inside Markdown body):
```html
<!-- printer_meta:
title: "DS18B20"
lines:
  - "±0.5°C • 3.0–5.5V • 1-Wire"
  - "Use: Temperature measurements"
qr_url: https://...  # Override front-matter qr_url
-->
<!-- /printer_meta -->
```

### MkDocs Macros (main.py)

Provides `{{ children() }}` macro for category index pages:
- Scans current folder for `.md` files
- Extracts titles from YAML front-matter or first H1
- Generates relative links (not absolute paths)
- Supports `exclude` and `recursive` parameters

Example usage in `docs/components/DC-DC Converter/index.md`:
```markdown
{{ children() }}
```

### QR Sticker Generation (build_labels.py)

- **Preset modes**: "compact" or "large" (configurable at top of script)
- **Dimensions**: 384px width (T02 printer), ~199px height (25mm @ 203 DPI)
- **Layout**: QR code left, text panel right (title, specs, component ID)
- **Text rendering**: Renders at 2-3x scale then LANCZOS downscale for sharp output
- **Fonts**: Uses TTFs from `fonts/` (DejaVuSans, DejaVuSans-Bold)
- **Short QR mode**: When enabled, generates `docs/qr/<ID>/index.html` redirects and uses short URLs like `https://thibserot.github.io/electronics-catalog/qr/TS001/`
- **Sheet packing**: Groups stickers into sheets of 4, maintains stable order via `assignment.json`
- **Outputs**:
  - Individual stickers: `docs/components/stickers/<ID>.png`
  - Packed sheets: `docs/components/stickers/sheet_001.png`, etc.
  - Metadata CSVs: `index.csv`, `sheets.csv`, `sheet_positions.csv`

### ID Registry (generate_id_registry.py)

Scans all `docs/components/**/*.md` files and produces:
1. **id_registry.yaml**: Full registry with all IDs, URLs, categories, families, used numbers, next available IDs
2. **id_registry_simple.yaml**: Simplified version for quicker lookups

The registry tracks:
- All component IDs and their metadata
- Category usage statistics (count, used numbers)
- Next available ID per category (`next_any`, `next_by_family`)
- Family groupings (only for anchored families where `CCXX00` index.md exists)

### Pre-commit Hook

Installed via `make precommit-install`, runs `make registry_stickers` before every commit to ensure:
1. Registry YAML is up-to-date
2. Stickers/QR codes are regenerated
3. Registry page is rebuilt
4. Generated files are auto-staged

## Workflow for Adding a Component

1. **Pick an ID**: Check `docs/components/stickers/id_registry_simple.yaml` for next available ID in category
2. **Create page**: `docs/components/<ID>.md` OR nested `docs/components/<Category>/<ID>.md`
3. **Add front-matter**: Include id, name, category, tags, short, use
4. **Fill content**: Pinout, wiring notes, gotchas, code examples, links (AliExpress, datasheet, tutorials)
5. **Generate stickers**: `make registry_stickers` (or let pre-commit hook handle it)
6. **Preview**: `make serve`
7. **Commit & deploy**: Push changes, run `make publish` for GitHub Pages

## Key Implementation Details

### URL Generation
- Component pages use folder-relative paths (not absolute)
- `build_page_url()` in scripts constructs GitHub Pages URLs from `docs/`-relative paths
- Index pages get folder URL: `docs/components/DC-DC Converter/index.md` → `/components/DC-DC%20Converter/`
- Regular pages get filename URL: `docs/components/TS001.md` → `/components/TS001/`

### Family Detection
- Family anchors require BOTH `number % 100 == 0` AND `index.md` filename
- `generate_id_registry.py` only creates family entries for valid anchors
- Non-anchored components in XXN00-XXN99 range are ignored unless anchor exists

### Sticker Sheet Packing
- Maintains stable order via `docs/components/stickers/assignment.json`
- New components append to end, existing components preserve positions
- Packs 4 labels per sheet with configurable gap (8px default)
- Optional dividers, cut lines, top/bottom borders

### MkDocs Plugins
- **awesome-pages**: Flexible navigation control
- **tags**: Tag aggregation and browsing
- **macros**: Custom `{{ children() }}` macro for dynamic content
- **search**: Full-text search across all components
